# 現行計画

`plans/` には、現行仕様に対する未完了または検討中の計画だけを置く。

実装済みの計画、完了記録、過去の比較案は通常の作業対象に含めない。
現行実装の正本は [`docs/spec/`](../docs/spec/) であり、計画の記述と食い違う場合は現行仕様とコードを優先する。
