# Yatagarasu 0.8.0

リリース準備中です。パッケージの公開とタグの作成は未実施です。

## 修正

- コミット後の一時的な書き込み競合によって、データベース全体が障害状態になる問題を修正しました。
- 既定値のキー、古い世代のキー、削除済みの対象への更新を、データの変更前に拒否します。
  対象が存在しない場合は`KeyNotFoundException`を送出します。`GraphStore.Write`の外側では、
  従来どおり`GraphOperationException`に包まれます。読み取り・存在確認・検索では、対象なしとして扱います。
- 読み取り開始時の重複処理を削減し、不変スナップショットの公開方法と読み取り側の登録方法を改善しました。
- ページの読み取り権限と書き込み権限を分離し、読み取り終了時の共通ロックを除去しました。
  書き込みの検証失敗時に、ページの固定を誤って解除する問題も修正しました。
- 常駐ページの検索を16個のシャードに分割しました。複数ページの並行読み取りが改善する一方、
  単一スレッドやページの追い出しを伴う処理には小幅な性能低下が残ります。
  同じ1ページに読み取りが集中する場合の競合も残っています。
- `Vacuum`による古いプロパティ版の回収をVertex・Edge・Nexusで統一し、未参照のベクトルデータも回収します。
- `VacuumMode.DryRun`はデータを変更せず、回収件数の予測を返します。変更済みページの退避書き出しや
  チェックポイントの実行も抑止します。`MaxDurationMs`は処理段階の境界で確認する目安であり、
  厳密な実行時間の上限ではありません。
- ベクトルの次元不一致をデータ変更前に拒否し、上位k件の検索結果で同点になった場合の順序を一定にしました。
- `Chunker`は有効なUTF-16サロゲートペアを分割しません。サイズ指定が1でも、2コード単位のスカラー値は
  長さ2の単独チャンクとして保持します。結合文字などを含む書記素クラスタ全体の保持は保証しません。

## 互換性

公開APIのシグネチャと、データおよびWALの保存形式（QUIVER-SW、バージョン2）は変更しません。
無効なキーによる更新時の例外動作は、上記のとおり変わります。
更新前には、データベースとWALおよび参照先の関連ファイルを一組としてバックアップしてください。

コアの実行時依存は引き続き.NET標準ライブラリのみです。HostingとOpenTelemetryは任意の追加機能です。
NativeAOTと大規模負荷の検証は、今回のローカル検証には含みません。

詳しい仕様は[ストレージ](../spec/01_storage_paging.md)、[トランザクション](../spec/03_mvcc.md)、
[システム概要](../spec/00_overview.md)、[API安定性](../api-stability.md)を参照してください。
